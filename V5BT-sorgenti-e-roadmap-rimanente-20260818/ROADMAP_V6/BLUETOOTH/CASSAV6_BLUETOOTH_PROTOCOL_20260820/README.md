# Cassa V6 Bluetooth Protocol

Implementazione Bluetooth attiva di Cassa V6.

Questa tree usa identita, UUID, domini crittografici, registri e stato separati
da Cassa V5BT. Algoritmi, framing e layout wire restano invariati; non esiste
migrazione automatica di chiavi, token, registri o prove fisiche V5BT.

La baseline storica V5BT resta byte-identica in
`ROADMAP_BLUETOOTH/CASSAV4_BLUETOOTH_PROTOCOL_BASE_ROADMAP_20260719`.
I suoi report non costituiscono evidenza per Cassa V6.
