# Riferimenti ufficiali

- Android Developers — Bluetooth permissions.
- Android Developers — Bluetooth Low Energy overview, scan, advertise and background communication.
- Google Developers — Nearby Connections overview/strategies, future optional transport.
- BlueZ — Adapter API, LE Advertising API, GATT API and Device API.
- Raspberry Pi documentation — Bluetooth/BLE capabilities for Raspberry Pi models.

Le versioni esatte delle dipendenze devono essere fissate durante B0/B1 e non lasciate come `latest`.
